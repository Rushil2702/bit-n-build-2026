# ClubOps AI 🚀

AI-powered event operations platform for college clubs.

ClubOps AI helps clubs manage events, tasks, volunteers, meetings, deadlines, risks and announcements in one centralized platform.

## Features

- Event Management
- Task Management
- Volunteer Management
- Meeting Management
- AI-powered Meeting Notes → Task Extraction
- Risk Management
- AI-assisted Announcements
- Event Dashboard

## Tech Stack

- Frontend: React, Vite, JavaScript, CSS
- Backend: Python, Flask, Flask-CORS
- Database: PostgreSQL, psycopg2
- AI: Google Gemini API

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```
